# 🌟 Quirky

A fun, quirky command-line productivity app built with Python.

Quirky helps you manage your tasks directly from your terminal with simple commands and fun productivity messages.

## ✨ Features

- ✅ Add tasks
- 📝 View your task list
- 🏆 Complete tasks
- 🗑️ Delete tasks
- 💾 Automatically saves your tasks
- 🚀 Fun productivity messages

## 📋 Commands

### ➕ Add a task

```bash
quirky add "Practice piano"
```

### 📝 View your tasks

```bash
quirky list
```

### ✅ Complete a task

```bash
quirky done 1
```

### 🗑️ Delete a task

```bash
quirky delete 1
```

### 🌟 Open the interactive menu

```bash
quirky
```

## 📦 Installation

Installation through Homebrew is coming soon!

For now, clone the repository:

```bash
git clone https://github.com/koderking25/quirky.git
```

Enter the folder:

```bash
cd quirky
```

Run Quirky:

```bash
python3 quirky.py
```
